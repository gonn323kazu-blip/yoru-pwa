YORU 更新版 2026-11-09

GitHub Pagesへの更新
1. このZIPを解凍し、中身を現在の公開元フォルダに上書きしてください。
   index.html / app.js / sw.js / style.css と icons / images を同じ階層に置きます。
2. GitHub Pagesの公開完了後、元と同じURL・同じブラウザで開き直してください。
3. 古い画面の場合は、一度アプリを閉じて再度開き、ページを再読み込みしてください。
   ブラウザのサイトデータは削除しないでください。

データ保持
従来のlocalStorageキーを使用します。旧睡眠記録、合計星数、設定、旧星座を保持します。
移行前データは端末内の yoru_before_daily_v2 に一度だけ保存します。
旧版の獲得日は、その日に記録された習慣1つを獲得済みとして引き継ぎます。
旧星座は「夜の星座（旧版）」として表示します。
データは公開URLのオリジン・ブラウザに紐付きます。別URLや別ブラウザへは自動移行しません。

今回の機能
・各3習慣で「はい」を選んだときだけ1日1星、合計最大3星。
・「いいえ」は星を付与しません。再挑戦できます。
・3習慣の星がそろうと当日1星座を保存し、再抽選しません。
・3星達成が連続した4日目に「3日坊主回避の星座」を確定付与。
  連続が途切れると1日目から数え直します。8日目等の4の倍数は通常抽選です。
・通常日はノーマル70%、レア25%、スーパーレア5%。各3種類から抽選。
  別の日には同じ星座が出る場合があります。日付とレアリティを保存します。
・睡眠記録の日付を選ぶと保存済み内容を読み込み、その日を編集できます。
  グラフは選んだ日付を末日として表示します。過去日入力で習慣の星は増えません。
・タイマー終了時に画面表示、対応環境で終了音・振動・許可済みOS通知。
  OS通知の許可は設定画面の「通知をテストする」から行います。
・PWAキャッシュはv9へ更新。元画像・アイコンは保持しています。

通知・タイマーの制限
アプリが開いている間の動作が基本です。OSがアプリを停止した場合、正確な時刻での通知は保証されません。
復帰時には実際の経過時刻を確認して終了します。音・振動・通知は端末の設定にも依存します。
バックグラウンドでの確実な通知にはサーバー側の追加機能が必要です。

実機での確認手順
・3習慣それぞれ終了後に「はい」。各1星、同じ習慣の再実施では追加なし。
・「いいえ」では追加なし。3星で星座表示、再読み込み後もコレクション保持。
・過去日を選び睡眠記録を保存し、再選択して読み込み・修正・グラフ確認。
・設定で通知を許可し、タイマー終了時の表示・音・振動・OS通知を確認。
・初回オンライン表示後、オフラインで再起動して画面を確認。
・更新前の記録・星・星座が引き継がれていることを確認。

プログラムテストの範囲は TEST-REPORT.txt を参照してください。

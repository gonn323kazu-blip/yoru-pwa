YORU 完成版PWA（研究用プロトタイプ）
====================================

【機能】
・スマートフォン向けレスポンシブUI
・ホーム／夜習慣／実践タイマー／完了演出／睡眠記録／設定
・星の獲得、週間の実施記録
・記録データに連動する折れ線グラフ（スマホ使用時間／寝つくまでの時間）
・グラフ期間を「1日／1週間／1か月／1年」に切り替え可能（1年表示は月ごとの平均値）
・記録日数の進捗表示と、記録内容に基づく振り返り
・「今日は選ばずに休む」でナビゲーションを隠し、おやすみ画面へ切り替え
・睡眠と就寝前スマートフォン使用の記録
・端末内保存（localStorage）
・CSVエクスポート
・PWAマニフェスト、アイコン、Service Workerによるオフラインキャッシュ
・通知のテスト（対応環境のみ）

【重要：アプリとしてインストールするには】
PWAはHTTPS（またはlocalhost）で配信する必要があります。index.htmlを直接開いただけでは、
ホーム画面へのインストールやService Workerが動かない場合があります。
このフォルダの中身をHTTPS対応の静的ホスティングへアップロードしてください。
例：GitHub Pages、Netlify、Cloudflare Pagesなど。
公開URLをAndroid Chromeで開き、ブラウザメニューからインストール／ホーム画面に追加。
iPhoneはSafariで開き、共有メニューから「ホーム画面に追加」。
※公開サービスのアカウント作成・設定は別途必要です。

【通知について】
現在の通知テストとリマインダーは、アプリが開いている間のチェックを基本とします。
ブラウザやPWAを完全に閉じている状態で指定時刻に確実に通知するには、
Web Pushとサーバー側スケジューリングなどの追加実装が必要です。iOS/Androidの挙動も確認してください。

【「今日は選ばずに休む」について】
Webアプリは、ブラウザからアプリやタブ自体を強制終了することができません。
このボタンではYORU内のナビゲーションを隠して、おやすみ画面に切り替えます。
画面を閉じる操作は利用者自身に行ってもらう設計です。

【データについて】
睡眠記録は利用中のブラウザのlocalStorageに保存され、サーバーには送信しません。
同じ端末でもブラウザが異なると記録は共有されません。ブラウザデータ消去で消える場合があります。
CSVエクスポート機能で記録を保存できます。
研究参加者に利用してもらう前に、同意説明、データ管理、匿名化、保存期間を決めてください。

【研究上の注意】
これは研究用の試作であり、医療的診断や治療を目的としません。
参加者に配布する前に、各端末での動作確認と、入力項目が研究計画に合っているかの確認を行ってください。


【改良版で追加した機能】
・習慣タイマー終了時の対応端末での振動
・呼吸、ストレッチ、静かな休息のガイド表示
・終了後の自己評価と1日1回の星獲得
・睡眠記録の傾向ヒントとAI相談文の作成（外部への自動送信なし）
・1週間に星を3つ集める星座コレクション

星や星座の追加データはこの端末のブラウザ内に保存されます。アプリのデータを消去すると失われる場合があります。
